## 三、关键结论速查

| 项 | 结论 |
|---|---|
| 健康检查 | 自定义组件以 Bean 名进入 components，DOWN 时返回 HTTP 503 |
| 指标四类 | Counter 单调递增、Gauge 抓取时读值、Timer 统计耗时与分位、Tags 拆分序列 |
| 名字改写 | `business.orders.created` → `business_orders_total`，点转下划线、补 `_total` |
| 分位窗口 | Micrometer 百分位为 1 分钟滚动窗口，只有 `_count`/`_sum` 是累计值 |
| 安全边界 | `exposure.include` 白名单逐个开放，`env` 等端点必须保持 404 |
| 验收手段 | 单元测试验打点逻辑，MockMvc 验端点，Apifox 验真实 HTTP 行为 |
